# Repository guidance

This is a documentation and learning repository, not a deployed application.

- Read the relevant guide and its source links; avoid scanning every document for a small edit.
- Keep work quick checks short, explain the output, and link to deeper troubleshooting.
- Mark state-changing examples and keep executable learning SQL under `labs/`.
- Use the MySQL 8.4 manual as the documented baseline. State the actual version used for any runtime verification.
- Never connect to a real work database or collect private logs merely to validate examples. Use an explicitly isolated disposable instance.
- Check local Markdown links, code-fence balance, and SQL examples affected by a change. Do not add dependencies or CI services for prose-only changes without a clear benefit.
- Do not add real credentials, internal hosts, customer records, or incident evidence to this public repository.
